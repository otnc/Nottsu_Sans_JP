Nottsu Sans JP
==============

Noto Sans JP の文字を、字形の中心から広がる４色で塗ったフォントです。

配色の出典は @Nottsu_fun26 (https://twitter.com/Nottsu_fun26)です。

インストール
------------

太さを 100〜900 の範囲で調整するには、NottsuSansJP-VariableFont_wght.ttf をインストールしてください。可変フォントに対応していないアプリでは、static フォルダーから使いたい太さの TTF を選べます。

色付きで表示するには、アプリが OpenType の COLR v1 に対応している必要があります。ただし可変フォントには SVG テーブルも入っているため、Safari などではそちらで色が表示されます。COLR v1 非対応環境向けの JavaScript 描画サンプルが examples/js-rendering フォルダーに入っています。
